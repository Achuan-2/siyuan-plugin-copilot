按需获取指定工具的补充使用说明、复杂操作示例和注意事项。

优先使用目标工具自带的描述和参数 schema 直接调用。仅在说明不足、需要复杂示例或遇到参数错误时读取补充文档；同一对话中已经读过的文档无需重复读取。

## 使用流程
1. 确定需要查阅补充说明的工具名称
2. 调用 get_siyuan_skills 获取该工具的详细文档
3. 阅读文档了解参数要求、使用示例、注意事项
4. 根据文档正确调用目标工具

## 参数
- toolName: 要查询的工具名称，如 "block"、"document"、"sql"、"plugin__siyuan_plugin_task_note_management__task" 等
